Ejercicio 3 CSS - San Pedro Claver

  1. Crear un nuevo proyecto llamado ejercicio_css_3_julian_ortiz
  2. Abrir el nuevo proyecto con Visual Studio Code.
  3. Crear el index.html.
  4. Crear la estructura básica de una página web.
  5. Crear la etiqueta style para aplicar los estilos CSS.
  6. Crear el título de la página web, con la etiqueta que corresponde. (El título puede ser cualquiera).
  7. Crear un Subtítulo de la página web con la respectiva etiqueta para ese fin.
  8. Crear una etiqueta div con el id contenedor.
  9. Dentro de la etiqueta div se va a insertar una imagen (Cualquier imagen). Se le debe colocar la clase claseimagenPrincipal y se deben aplicar estilos a esta imagen con CSS usando el selector de clase.
  10. Se deben crear dos etiquetas p dentro de la etiqueta div, y se le deben aplicar estilos con ayuda de los selectores combinados.
  11. Crear un footer donde se debe colocar el nombre de la persona que desarrolló la actividad.
