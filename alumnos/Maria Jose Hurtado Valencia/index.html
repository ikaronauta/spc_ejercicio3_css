EJERCICIO 3-CSS.

CSS es el lenguaje que define el diseño y la apariencia de las paginas web.

CSS, o hojas de estilo en casada es un lenguaje utilizado para definir la presentacion y el estilo de docuentos HTML o XML. Basicamente, permite controlar la apariencia visual de las paginas web, como colores, fuentes, diseño y disposicion de los elementos. CSS separa el contenido (HTML) del diseño, lo que facilita la gestion y el mantenimiento de los sitios web. CSS permite separar el contenido de un documento(generalmente HTML) de su apariencia visual. Esto significa que puedes cambiar el diseño de tu sitio web sin modificar el contenido en si.
