EJERCICIO 3-CSS

CSS es el lenguaje que define el diseño y la apariencia de las paginas web

CSS, o Hojas de Estilo en Cascada, es un lenguajo utilicado para definir la presentación y el estilo de documentos HTML o XML. Básicamente, permite controlar la apariencia visual de las páginas we, como colores, fuentes, diseño y disposición de los elementos. CSS separa el contenido (HTML) del diseño, lo que facilita la gestión y el mantenimiento de los sitios web. CSS permite separar el contenido de un documento (generalmente HTML) de su apariencia visual. Esto significa que puedes cambiar el diseño de tu sitio web sin modificar el contenido en sí.
