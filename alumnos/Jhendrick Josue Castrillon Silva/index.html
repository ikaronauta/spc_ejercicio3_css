ejercicio 3 - css

css es el lenguajes que define el diseño y la apariencia de las paginas web.

css,o hojas de estilos en cascada, es un lenguaje utilizado para definir la presentetacion y el estilo de documentos html o xml. Basicamente, permite controlar la apariencia visual de las paginas web, como colores, fuentes, diseño y disposicion de los elementos. css separa el contenido (html) del diseño, lo que facilita la creacion de paginas
