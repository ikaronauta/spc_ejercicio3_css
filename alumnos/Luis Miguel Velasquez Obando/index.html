pagina con estilo

css, o hojas de estilo en cascada, es un lenguaje utilizado para definir la presentacion y el estilo de documentos HTML o xml, basicamente, permite controlar la apariencia visual de las paginas web, como colores, fuentes, diseño y disposicion de los elementos. css separa el contenido(html) del diseño, lo que facilita la creacion de paginas
