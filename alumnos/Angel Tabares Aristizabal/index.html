EJERCICIO 3-CSS

CSS es el lenguaje que define el diseño y la apariencia de las paginas web

CSS o hojas de estilo en cascada, es un lenguaje utilizado para definir la precentacion y el estilo de documentos HTML O XML.Basicamente permite controlar la apariencia visual de las paginas web,,como colores ,fuentes, diseño, y disposicion de elementos.CSS separa el contenido (HTML) del diseño,lo que facilita la gestion de el mantenimiento de los sitios web. CSS permite separar el contenido de un documento
